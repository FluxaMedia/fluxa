## Build from source

```bash
git clone https://github.com/FluxaMedia/fluxa.git
cd fluxa
./native/fluxa-mpv/fetch-libmpv.sh
cargo run --release --manifest-path native/Cargo.toml -p fluxa-desktop
```

Other platforms and checks are in [CONTRIBUTING.md](CONTRIBUTING.md).
