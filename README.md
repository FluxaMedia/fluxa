# Fluxa

Fluxa is a cross-platform media hub for discovering, organizing, and watching content from user-installed Stremio addons.

It supports Android, Android TV, iOS, tvOS, Windows, macOS, Linux, web, and webOS through shared application logic and platform-specific interfaces.
