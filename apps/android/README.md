# Android platform shell

This directory contains Fluxa’s Android, Android TV, and shared Kotlin Multiplatform modules.

For the project overview and contribution rules, see the repository [README](../../README.md) and [CONTRIBUTING](../../CONTRIBUTING.md).

Typical local builds:

```bash
./gradlew --offline :app:assembleMobileDebug
./gradlew --offline :app:assembleTvDebug
```
