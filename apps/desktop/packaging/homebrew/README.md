# Homebrew Cask

`Casks/fluxa.rb` is the cask definition for the `FluxaMedia/homebrew-fluxa` tap.

After that tap repository is created, users can install Fluxa Desktop with:

```sh
brew tap FluxaMedia/fluxa
brew install --cask fluxa
```

The cask tracks the universal DMG from the Fluxa GitHub release. Update its
version, release URL, and SHA256 when publishing a new desktop release.
